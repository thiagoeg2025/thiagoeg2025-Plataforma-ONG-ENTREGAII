# Plataforma ONG — Entrega II  
## Estilização com CSS3, Design System e Layout Responsivo

Esta entrega corresponde à implementação da camada visual da plataforma desenvolvida na Entrega I.  
O objetivo é aplicar técnicas modernas de CSS3, responsividade e construção de sistemas de design.

---

## 🎨 Objetivos da Entrega

- Criar um **design system completo** com variáveis CSS.
- Aplicar **tipografia, paleta de cores e sistema de espaçamentos**.
- Implementar **layout responsivo** usando Flexbox e Grid.
- Criar componentes reutilizáveis como:
  - Botões  
  - Cards  
  - Navegação  
  - Estrutura de formulários  
- Implementar um **menu responsivo** com submenu e versão mobile.

## 🧩 Componentes Criados

### ✔ Paleta de Cores (mínimo 8 cores)
- Cores primárias  
- Cores secundárias  
- Tons neutros  
- Cores de estados (hover, foco, desabilitado)

### ✔ Tipografia Hierárquica  
- 5 níveis de tamanhos de fontes  
- Aplicação em títulos, subtítulos, corpo de texto e componentes  

### ✔ Sistema de Espaçamento  
- Baseado em:  
  - 8px  
  - 16px  
  - 24px  
  - 32px  
  - 48px  
  - 64px  

### ✔ Layout Responsivo  
- Grid principal com 12 colunas  
- Breakpoints definidos para:
  - Mobile
  - Tablet
  - Desktop
  
### ✔ Componentes desenvolvidos  
- Header com menu responsivo e submenu  
- Cards para projetos  
- Sistema de tags (badges)  
- Botões com estados  
- Formulários estilizados  
- Rodapé padronizado
